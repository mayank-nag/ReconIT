# Security Policy

## Responsible Disclosure & Ethical Use

**ReconIT (Venom)** is designed strictly for authorized, defensive security research, attack surface management, and educational evaluation.

### Supported Versions

Security updates and patches are actively maintained for the latest stable release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

### Reporting a Vulnerability

If you discover a security vulnerability within ReconIT (such as parser issues, injection risks, or credential handling flaws):

1. **Do not open a public issue.**
2. Send a detailed report via email to **security@reconit.dev** (or open a private GitHub Security Advisory).
3. Include:
   - Description of the vulnerability and potential impact
   - Minimal reproducible proof of concept (PoC)
   - Any remediation suggestions
4. We will acknowledge receipt of your vulnerability report within **48 hours** and provide periodic updates until a fix is published.

### Scope & Legal Notice

ReconIT conducts low-impact, non-intrusive reconnaissance against user-specified targets. Users are solely responsible for ensuring they possess explicit authorization prior to scanning third-party infrastructure.
